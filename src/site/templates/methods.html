Licensed research is credited, never reproduced

Some figures come from Barclays, J.P. Morgan and Freedom Broker notes and from a Bloomberg terminal export. Those documents are licensed to a named individual and are marked as not for reproduction or redistribution. We cite the figures and attribute them, and the files themselves are excluded from the public repository. Anything published here is either a public-domain government source, a company filing or disclosure, a press report, or our own calculation.

Hand-curated datasets

Neither Copart nor RB Global publishes a machine-readable panel of operating metrics such as unit growth by segment, average selling prices or cost per car. Those figures exist only in earnings-call transcripts and research notes, so they are transcribed by hand into data/manual. Every row carries a source column naming the document it came from, and derived rather than reported values are labelled as derived.

Rules we hold ourselves to

  • No invented numbers. If a figure is not in a filing, a transcript, a public dataset or our own calculation from those, it does not appear.
  • Derived is labelled derived. Where we computed something the company did not report, such as RB Global's implied Q1 take rate, the table says so.
  • Scraped counts are listings, not sales. Inventory-tracker output is always described as listings observed, never as reported unit sales.
  • Models state their sample size. Every regression reports its number of observations, R-squared and confidence interval, and we say plainly when a sample is small.
  • Every chart has a table. No value is reachable only by hovering, which also keeps the site readable in print and for colour-vision-deficient readers.
  • Disconfirming evidence gets equal billing. The competitive data that supports the bear case is presented first on its own page, not buried.

Reproducing this site

  1. Clone the repository and create the virtual environment.
  2. Copy .env.example to .env and set at least SEC_USER_AGENT to your name and email, which the SEC requires.
  3. Run python -m src.collect.sec_financials and python -m src.collect.macro.
  4. Run python -m src.build.tlf_nowcast.
  5. Run python -m src.site.build_site and open docs/index.html.

The full step-by-step version, written for someone who has never used an API key, is in SETUP.md in the repository.
